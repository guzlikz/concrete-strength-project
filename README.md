# Прогнозирование прочности бетона

**Поздин Марат Евгеньевич**, ученик 11Б класса МБОУ лицей №7.

Учебный проект на Python: прогноз прочности на сжатие по составу смеси и возрасту. Сравнение линейной регрессии и случайного леса, графики, разбор крупнейших ошибок. Объём соответствует небольшому проекту на 3–5 часов самостоятельной работы, без веб-приложения и сложных нейросетей.

[Открыть выполненный ноутбук](concrete_strength.ipynb) · [Скачать презентацию PowerPoint](Concrete_Strength_Pozdin_Marat.pptx) · [Текст для защиты](defense.md)

## Результат

Тест содержит 206 наблюдений из 86 рецептур, которых нет в обучении. Лес снизил RMSE относительно линейной регрессии на **38.8%**.

| Модель | MAE, МПа | RMSE, МПа | R² |
|---|---:|---:|---:|
| Среднее | 14.48 | 18.02 | -0.006 |
| Линейная регрессия | 8.68 | 10.79 | 0.639 |
| Случайный лес | 4.62 | 6.60 | 0.865 |

Это оценка на одном фиксированном разбиении, а не гарантия качества для любого бетона.

## Как устроена проверка

1. Удаляем 25 полных повторов из 1030 строк. Остаётся 1005 наблюдений. Пропусков нет.
2. Группируем строки по семи дозировкам компонентов без возраста. Всего 428 точных рецептур. Измерения одного состава в разном возрасте всегда остаются вместе.
3. `GroupShuffleSplit(test_size=0.2, random_state=42)` откладывает 20% групп: 799 строк train и 206 строк test. Доля строк не обязана совпадать с долей групп.
4. Исследуем train. Сравниваем среднее train, линейную регрессию с `StandardScaler` внутри `Pipeline`, случайный лес из 300 деревьев.
5. `GroupKFold(5)` и `GridSearchCV` выбирают параметры леса по RMSE внутри train. Проверяем 8 вариантов: глубина `None` или 15, минимум листа 1 или 3, доля признаков 0.8 или 1.0. Победитель: `{'max_depth': 15, 'max_features': 0.8, 'min_samples_leaf': 1}`.
6. Один раз оцениваем модели на test. После диагностики ошибок не перенастраиваем их. Важность признаков — диагностическая перестановка в test, 20 повторов.

CV у выбранного леса использована для настройки и может быть оптимистичной. Независимую итоговую оценку даёт test. Близкие, но не идентичные рецептуры могут находиться в разных частях. Данные не позволяют оценить перенос на другой завод или другую лабораторию.

## Что означают метрики

- MAE: среднее значение `abs(прогноз − факт)` в МПа.
- RMSE: квадратный корень из среднего квадрата ошибок, в МПа. Сильнее учитывает крупные промахи.
- R²: `1 − сумма квадратов ошибок / сумма квадратов отклонений от среднего test`. Ближе к 1 лучше, возможны отрицательные значения. Это не «процент точности».
